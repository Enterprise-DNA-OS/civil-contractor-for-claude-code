# Update an operational record

Read the current record and identify the evidence for the correction. Run `npm run civil -- set <entity> <id or name> --data=<json-file>`. Competencies, inductions, service dates and prestart corrections need actual evidence. Read the schema for field names. The CLI checks allowed fields, allocation readiness and locks approved dockets. Diary corrections are new notes, and timesheet corrections require source reconciliation. Never invent a passed check to clear a hold.
